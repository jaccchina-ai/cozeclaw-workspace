# T01 选股系统策略更新记录

## 2026-04-20 卖出策略更新

### 新卖出规则
- **T+2 日处理**:
  - 如果涨停: 卖出一半仓位，持有另一半
  - 如果不涨停: 收盘价全部卖出

- **T+3 日及以后处理**:
  - 如果持有仓位且涨停: 继续持有
  - 如果持有仓位且不涨停: 收盘价卖出剩余一半
  - 以此类推，直到全部卖出

### 胜率和盈利统计更新
- **新胜率定义**: 最终全部卖出后，总收益为正即算盈利
- **新盈利计算**: 统计多次卖出的平均收益
- **计算方式**: (第一次卖出金额 + 第二次卖出金额 + ...) - 总买入金额

### 系统变更
- 数据库新增字段: shares_held, sell_history, final_profit
- 跟踪逻辑重新实现支持多日分批卖出
- 飞书消息推送优化显示卖出历史和剩余仓位
