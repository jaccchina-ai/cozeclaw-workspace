# 竞价选股策略升级说明

## 📋 升级内容

1. **选股逻辑变更**
   - 从"硬性选择前3名"改为"综合判断后选择不超过3名"
   - 根据多种条件智能判断，避免机械截断

2. **综合判断因子**
   - 🎯 **分数阈值**: 最低80分门槛
   - 📉 **市场风险适配**: 高风险环境少选，低风险环境多选
   - 📊 **板块分散**: 同一板块最多选2只
   - 📈 **分数差距判断**: 分数接近时不硬性截断，差距过大时提前停止
   - 🔍 **技术形态识别**: 优先选择弱转强、竞价爆量等模式，规避连续一字板等风险形态

3. **配置文件**
   - `auction_selection_config.json` 可灵活调整各因子参数
   - 支持开关控制各因子是否启用

4. **使用方式**
   - 原有API接口保持不变
   - 系统自动应用新的选股逻辑

## 🧪 测试验证

```bash
python3 test_auction_selection.py
```
