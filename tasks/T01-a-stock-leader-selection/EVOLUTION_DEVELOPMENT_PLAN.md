# T01 选股系统 - 策略进化开发计划

## 1. 项目背景
当前T01选股系统使用固定权重的多因子模型，已成功运行1个月。为了适应市场变化，需要引入策略进化机制，让系统能够自动优化因子权重，提升选股胜率和稳定性。

## 2. 目标
- 开发基于遗传算法的策略进化系统
- 实现自动回测、进化和部署流程
- 目标胜率提升至65%以上
- 降低最大回撤至15%以内

## 3. 技术架构

### 3.1 核心模块
```
T01选股系统
├── 数据层 (Tushare数据获取)
├── 策略层 (多因子评分模型)
├── 回测层 (历史数据回测)
├── 进化层 (遗传算法优化)
└── 部署层 (自动化更新)
```

### 3.2 进化流程
```
初始化种群 → 回测评估 → 选择操作 → 交叉操作 → 变异操作 → 下一代种群 → ... → 满足停止条件
```

## 5. 关键指标

### 5.1 进化性能指标
- 进化代数：100代
- 种群大小：50个策略
- 回测天数：60天
- 进化时间：<1小时/代

### 5.2 策略质量指标
- 胜率目标：>65%
- 平均收益：>2.5%
- 最大回撤：<15%
- 夏普比率：>1.0

## 6. 技术选型

### 6.1 算法选择
- **遗传算法**：使用DEAP库实现
- **回测引擎**：自定义实现，结合Tushare数据
- **并行计算**：使用multiprocessing加速回测

### 6.2 数据管理
- **历史数据**：存储在PostgreSQL
- **进化结果**：JSON文件存储，便于分析
- **策略备份**：自动备份机制
