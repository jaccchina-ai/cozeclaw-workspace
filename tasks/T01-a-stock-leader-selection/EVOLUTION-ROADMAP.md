### Phase 1: 基础优化 (Week 1-2) - 立即开始
**目标**: 解决多重共线性，提升因子质量

#### 1.1 因子正交化处理 ⭐⭐⭐⭐⭐
**优先级**: 最高（基础）  
**原因**: 现有因子存在高度相关（如封单金额 vs 封成比），导致评分失真  
**实现**:
- 使用 PCA 提取主成分（保留90%方差）
- 或 Gram-Schmidt 正交化
- 计算因子相关性矩阵，自动识别高相关因子对

**技术方案**:
```python

from sklearn.preprocessing import StandardScaler

# 1. 因子标准化
# 2. PCA降维/正交化
# 3. 反向映射得到正交化后的因子值
```

**验收标准**:
- [ ] 因子相关性矩阵可视化
- [ ] 正交化后因子间相关性<0.3
- [ ] 保留90%原始信息

### Phase 2: 核心增强 (Week 3-4)
**目标**: 自动优化权重，提升选股收益

#### 2.1 遗传算法权重优化 ⭐⭐⭐⭐⭐
**优先级**: 最高（核心）  
**原因**: 直接决定选股效果，自动化权重调整  
**实现**:
- ✅ 使用 DEAP 实现遗传算法 (`genetic_optimizer.py`)
- 优化目标: 最大化胜率 + 夏普比率
- 约束条件: 权重和为1，各权重>0

**技术方案**:
```python
# genetic_optimizer.py 已创建
from deap import base, creator, tools, algorithms

# 遗传算法参数：
# - 种群大小: 50
# - 迭代代数: 100
# - 交叉概率: 0.7
# - 变异概率: 0.2
# - 选择算子: 锦标赛选择
# - 适应度函数: 胜率*0.5 + 夏普比率*0.3 + 总收益*0.2
```

**模块功能**:
- `GeneticWeightOptimizer`: 遗传算法优化器类
- `BacktestResult`: 回测结果数据结构
- `evaluate_individual()`: 个体适应度评估
- `backtest_weights()`: 权重回测
- `compare_with_current()`: 对比优化前后权重

**验收标准**:
- [ ] 遗传算法收敛稳定
- [ ] 优化后胜率提升>5%
- [ ] 提供权重变化历史
